- La matriz cubre las historias del Product Backlog desarrolladas en Sprint 1, Sprint 2 y Sprint 3: HU-01–12, HU-14–25, HU-27–37. HU-13 y HU-26 no aparecen en el alcance vigente consultado.

## Casos transversales de integración y E2E (T66)

1. **Flujo feliz:** login Coordinador → registrar solicitud y antecedentes sintéticos → asignar dos Docentes → login de cada docente → análisis determinista + agente simulado → registrar revisiones → consultar/generar informe → remitir → Coordinador decide si aplica y finaliza.
2. **Permisos:** no autenticado = 401; rol incorrecto = 403; recurso de otro docente según contrato = 404; comprobar acceso legítimo por Gateway, nunca llamada directa permitida a microservicios.
3. **Fallo/incompleto:** agente simulado con error o datos incompletos; no presentar resultado ficticio ni permitir transición que exige análisis completo.
4. **Persistencia:** reiniciar servicios tras cada hito persistente; comprobar estados, revisiones, adjuntos e informe según sus historias.
5. **Concurrencia/estado final:** dos remisiones/generaciones simultáneas no duplican el evento; tras finalizar no se editan solicitud, análisis ni informe.

Los casos 2–5 son escenarios del plan; no se declaran aprobados hasta que T66/T67 y el recorrido de Docker Compose tengan evidencia.
